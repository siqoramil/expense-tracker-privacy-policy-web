# expense-tracker-pp-web

Privacy Policy website for the **Expense Tracker** mobile app, built with React + TypeScript + Vite + Tailwind CSS v4.

## Stack

- React 19
- TypeScript
- Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`)

## Develop

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
```

Output goes to `dist/`. Deploy `dist/` to any static host (Vercel, Netlify, GitHub Pages).

## Content source

The privacy policy text mirrors `docs/privacy.html` — the canonical version included with the mobile app.
